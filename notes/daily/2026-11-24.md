## 💡 Decisions & Lessons Learned
- **Pure Graph vs. Hybrid**: A pure graph lacks transactional locks and crash idempotency. The optimal architecture is a 3-pillar hybrid: Anthropic MCP / REST (Protocol) + SQLite Event Log (Idempotency & Leases) + NetworkX DAG (Dependency & Blast Radius).
- **Two-Laptop Demo Advantage**: Demonstrating live cross-laptop agent coordination over WebSockets provides immediate visual differentiation over single-machine scripts.
- **Scoped Subgraphs vs Chat Dumps**: In Gate 3, extracting only immediate parent requirements produced an agent prompt of only ~195 tokens, slashing token costs by >90% while providing 100% relevant context.
